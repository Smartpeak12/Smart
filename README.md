# SmartPeak Real Estate Website

A modern, responsive real estate website for buying, selling, and renting properties.

## Features

✅ **Browse Properties** - Explore available properties for sale and rent
✅ **Advanced Filtering** - Filter by type, location, price, and bedrooms
✅ **Search Functionality** - Quick search for properties
✅ **Admin Panel** - Manage properties (add, edit, delete)
✅ **Favorites** - Save your favorite properties
✅ **Dark Mode** - Light/Dark theme toggle
✅ **Multi-language Support** - 5 languages supported (English, Spanish, French, German, Chinese)
✅ **Responsive Design** - Works on all devices
✅ **PWA Ready** - Can be installed as an app
✅ **Analytics** - Track user interactions

## Pages

- `index.html` - Main homepage with property listings
- `admin.html` - Admin panel for managing properties
- `favorites.html` - View saved favorite properties

## Files

- `styles.css` - All styling and responsiveness
- `app.js` - Main application logic
- `admin.js` - Admin panel functionality
- `dark-mode.js` - Dark mode toggle
- `i18n.js` - Multi-language support
- `analytics.js` - Analytics tracking
- `manifest.json` - PWA configuration

## How to Use

1. **View Properties** - Browse available properties on the homepage
2. **Search & Filter** - Use the search bar and filters to find properties
3. **Add to Favorites** - Click the heart button to save properties
4. **Admin Panel** - Add, edit, or delete properties
5. **Toggle Theme** - Click the theme button to switch between light and dark modes
6. **Change Language** - Select a language from the dropdown

## Deployment

### GitHub Pages
1. Go to repository settings
2. Navigate to "Pages"
3. Select "main" branch
4. Your site will be live at: `https://smartpeak12.github.io/Smart/`

### Netlify
1. Go to https://app.netlify.com
2. Click "New site from Git"
3. Select your GitHub repository
4. Deploy
